# MemberPulse

A polished, responsive product trial for a gym member-retention workspace. The concept helps gym owners find at-risk members early, prioritize follow-ups, and turn expiring memberships into simple renewal conversations.

## Included screens

1. **Retention overview** — live KPIs, attendance trends, renewal progress, priority follow-ups, and daily actions.
2. **Members & risk** — searchable member directory with lifecycle filters, risk scoring, bulk selection, and contextual actions.
3. **Member 360 & renewal** — risk drivers, attendance decline, member activity, follow-up planning, and a guided renewal-link flow.

## Interactions

- Navigate between all three screens from the sidebar.
- Filter, search, select, and sort members.
- Open a personalized WhatsApp/SMS/email follow-up drawer.
- Create and send a renewal link from Nina Patel's profile.
- Switch reporting ranges and use contextual dashboard actions.
- Use the responsive navigation and layouts on mobile screens.

## Run locally

No build step or dependencies are required. Open `index.html` directly, or serve this directory with any static file server.

## Implementation

Built with semantic HTML, custom CSS, inline SVG icons, and vanilla JavaScript. All member data is fictional and created for this product demonstration.
